A mutation cannot land without its poke — the pairing is the interface, not a checklist. The six hand-written handlers collapse back to the macro.

Problem. The Poke rule lives as discipline in six hand-written mutations plus a ~270-line text-scanning guard — no module owns it.

Solution. Pair each mutation with its channel poke behind one interface, so the poke ships with the mutation.

  • locality: the poke lives in one module
  • leverage: one macro, every entity pokes
  • delete the ~270-line text guard
  • a new entity (Post, Caption) pokes for free
  • interface shrinks; the macro absorbs the trio
  • guard proves execution, not text presence
Two adapters justify the seam — here there are three: agents, convs, and conv:{id} pokes. The variation across the seam is real, not hypothetical.

The port already exists — both view-models accept feed?. Create one adapter at the boundary (like AuthProvider) and pass it down.

Problem. The Feed adapter is instantiated per view-model, so one client holds two live sockets, each with its own reconnect machinery.

Solution. Instantiate one MessageFeed at the authenticated boundary and inject it through the seam both view-models already accept.

  • one socket per client, not two
  • locality: reconnect + back-off run once
  • leverage: the port already exists
  • fewer connections for #91 rate-limiting
  • tests unchanged — same feed seam
Compatible with ADR-0015. One connection still subscribes per-channel and is authorized per-channel at subscribe-time; sharing the socket does not widen the push scope.

Complements AR C02. The back-end already gave the routing key a Channel type (commit 5660782). This is the front-end mirror — the smaller, cheaper half of that seam.
Speculative in-process Candidate 4

After — one createSelectableList<T>?

A generic createSelectableList owning resource + reconcile + select + create — if the two halves truly share a shape.

Problem. Agent and Conversation each repeat the resource/select/create shape; the interface exposes ~24 members in matched pairs.

Solution. Consider a createSelectableList<T> deep sub-module the two halves configure.

Caveat — may be a false economy. The halves diverge: the conv resource keys on the selected Agent and showArchived; the agent side carries a delete-cascade selection collapse the conv side lacks. Forcing a shared generic could add complexity, not concentrate it — the deletion test may come back “just moves it.” Flagged Speculative for exactly that reason; worth a design-it-twice pass before any change.
Resolved 2026-09-03 — no-go. Grilled to a verdict: two divergent callers today, Message is a stream, and the #31 merge dissolves the shape — top level static, the rest WebSocket streams. No generic; the code stays as-is.

Give the Poke rule a structural home

It sits on the hottest files, and the ~270-line text-scanning guard is prima-facie proof of a missing seam: a domain rule with no module to own it. Three real pokes justify the seam.
