Add a channel in one place. The type carries the rest.

The compiler forces each match to be exhaustive, but WsEvent::channel() maps variant→variant by hand — a wrong arm still compiles. Tests (jedi_poke_wire_shape_is_stable, jedi_channel_keys_are_stable) backfill the guarantee the structure does not carry.

Problem
A channel is spelled in three enums plus four match arms; they stay in sync by hand and by test.
Solution
One Channel descriptor owns kind string, id-arity, routing key, and authorize rule; WsEvent holds a Channel.

Wins

  • → locality: one place per channel
  • → leverage: #113 payloads add once, not 7×
  • → interface shrinks; routing absorbs the matches
  • → wire-shape tests stop being the guarantee
Shipped per ADR-0020 (commit 00f2790). The final form went further than this sketch: the three types merge into one exported Channel, ChannelKind is removed, and the front-end channel.ts mirror is rebuilt on the generated Channel. The wire is broken by design — back-end and front-end shipped together.

C-05 · Build the typed poke receipt ADR-0016 already chose

Strong ✓ Shipped

backend/crates/services/web-server/src/web/rpcs/mod.rs · docs/adr/0016-poke-rule-typed-receipt.md

Before — ~260-line source-scan guard

strip_line_comments()
balanced_parens()
handler_idents()
router_builder_names()
fn_body() — assumes column-0 brace
POKE_TABLE — hand-maintained

Test-time. Proves presence, not execution. Blind outside 4 name prefixes.

After — one compile-time obligation

broadcast_*() → PokeReceipt<C>

create_agent()
  -> PokedRpcResult<Agent, Agents>

No poke → no receipt → no return value → no compile.

Wrong-feed poke is a type error. Wire shape byte-identical.

Problem
The Poke rule rides on a fragile Rust-text parser run at test time — the guard's own notes call it heavy and leaky.
Solution
The decided PokeReceipt<C> / PokedRpcResult<T, C>; delete the scanner and POKE_TABLE.

Wins

  • → delete ~260 lines of parser
  • → compile-time, not test-time
  • → covers every mutation, any name
  • → locality: the type is the rule
Shipped — implements ADR-0016. PokeReceipt<C> / PokedRpcResult<T, C> are in the tree; the source-scan guard and POKE_TABLE are deleted (net −215 lines). Delivered in #135 (merged, 404c12f), closing #102. Accepted limit: a mutation typed as DataRpcResult<T> bypasses the token; the crud_with_poke! macro stays deferred (#66).
