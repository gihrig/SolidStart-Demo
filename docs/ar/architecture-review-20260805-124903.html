Small interface, deep implementation. Test crosses the same seam Nav does.

// Nav.tsx:24-25, 70 — the blend, inline in the component
const [profile] = createResource(() => jediApi.profile.get());
const displayName = () => (isAuthenticated() ? username() : profile.latest?.name);
<img src={profile.latest?.avatarUrl} alt={displayName() ? `${displayName()} avatar` : ""} />

Problem. The unified-identity blend — the structural point of #62 — is the one view-model derivation left inline in a component, reachable only by rendering <Nav />.

Solution. Move the blend behind a small interface (a new identity module, or a deepened useAuth) exposing displayName + avatarUrl; Nav reads them.

Wins

  • locality: blend rule in one module
  • interface is the test surface — no DOM
  • leverage: #17 swaps source behind the seam
  • Nav's interface shrinks to two reads
  • surfaces the alt-text vs mock-avatar mismatch
ADR-0007 — realizes its "unified identity" direction and names the concept #17 edits. No conflict.

Deeper: same implementation, interface trimmed to the route's reads.

// index.tsx destructures 11; createJediFeed.ts exposes 15.
// posts / featured / topCaptions / winningCaption — read only in createJediFeed.unit.test.ts
expect(feed.featured()?.id).toBe(1); // asserts a derivation via an extra accessor
expect(feed.selectedPost()?.id).toBe(1); // …the route's real accessor already proves it

Problem. Four accessors are exposed purely as the test's read surface, so the interface is wider than the route — the real caller — needs.

Solution. Return only what the route consumes; assert the derivations through those accessors (the interface is the test surface).

Wins

  • interface shrinks 15 → 11
  • test crosses the route's seam
  • delete 4 test-only accessors
  • interface matches the real caller

Milder than a leak: a within-module trim. Some intermediates may earn their place — settle that when designing the interface.
